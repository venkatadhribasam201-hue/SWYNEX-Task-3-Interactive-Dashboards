# SWYNEX Task 3 - Interactive Dashboard

## 📊 Project Overview

This project was completed as part of the **SWYNEX Technologies Data Analyst Internship**.

The objective of Task 3 was to create an interactive dashboard using **Microsoft Power BI** based on the cleaned and analyzed dataset prepared during the previous internship tasks.

The dashboard presents key metrics, customer characteristics, campaign responses, income and spending patterns, and other relevant findings through interactive visualizations and filters.

---

## 🎯 Objective

The main objectives of this task were to:

* Build an interactive business dashboard
* Present important KPIs clearly
* Visualize patterns and trends in the dataset
* Provide interactive filtering using slicers
* Communicate analytical findings through charts
* Create a clear and easy-to-understand dashboard layout
* Apply data visualization and dashboard design principles

---

## 🛠️ Tool Used

**Microsoft Power BI**

Power BI was used to create the interactive dashboard, including:

* KPI cards
* Slicers
* Charts
* Tables/visual elements
* Interactive filtering
* Dashboard formatting
* Data visualization

---

## 📂 Dataset

The dashboard was developed using the **cleaned dataset prepared during the previous SWYNEX internship tasks**.

The data was cleaned and prepared before being used for exploratory analysis and dashboard development.

The preparation process included checking and handling:

* Missing values
* Duplicate records
* Data types
* Data consistency
* Unnecessary columns
* Data quality issues

---

## 📈 Dashboard Components

The dashboard contains multiple visual elements designed to provide an overview of the dataset.

### KPI Cards

The dashboard includes KPI cards to provide quick access to important summary metrics.

These allow users to understand the overall dataset at a glance.

### Interactive Slicers

Interactive slicers are included to allow users to filter the dashboard and explore different segments of the data.

### Age Analysis

Visualizations are used to understand the distribution and characteristics of customers across different age groups.

### Education Analysis

The dashboard provides a visual analysis of customer education levels.

### Campaign Response Analysis

A campaign response visualization is included to examine customer responses to marketing campaigns.

### Income and Spending Analysis

A scatter visualization is used to explore the relationship between customer income and spending-related variables.

## 📊 Data Analysis Approach

The dashboard development followed a structured process:

1. **Data Collection**

   * Used the dataset provided/selected for the internship task.

2. **Data Cleaning**

   * Checked missing values, duplicates, data types, and inconsistencies.

3. **Exploratory Data Analysis**

   * Examined the dataset to identify patterns, relationships, and important observations.

4. **Dashboard Development**

   * Imported the prepared dataset into Power BI.
   * Created KPIs, charts, slicers, and other visual elements.

5. **Dashboard Formatting**

   * Organized the visuals into a clear dashboard layout.
   * Applied consistent formatting for readability.

6. **Final Review**

   * Checked the dashboard interactions and visual presentation before submission.
